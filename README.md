# E-Library

Автор: Татымов Алекксаедр, 25ИС-11Д

## Описание
Учебный проект: электронная бибилиотека (консольное приложение).

## План функций
- Добвать книгу
- Показать список по требованию
- Изменить статус книги
- Списать книгу

## Стек
C# / .NET / Visual Studio

## Как запустить
1) Открыть solution в Visual Studio
2) Нажать F5 (Run)
3) В консоли появится меню
