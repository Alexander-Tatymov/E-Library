# ТЗ: E-Library

## 1. Название
	E-Library (Электоронная Библиотека)

## 2. Цель
	Программа помогает хранить, выдавать электронные книги,
	поддерживать и расширять фонд, а также, удалять книги из фонда.

## 3. Пользователь
	Обычный пользователь ПК (студент).

## 4. Функциональные требования (FR)
- FR1: Добавить книгу в фонд
- FR2: Выдать книги пользователю
- FR3: Возвращать книги в фонд
- FR4: Списывать книги

## 5. Нефункциональные требования (NFR)
- Приложение запускается без ошибок
- Понятные сообщения об ошибках 
- Данные будут храниться локально
- Понятные запросы от пользователя

## 6. Модель данных (черновик)
**Задачи E-Library**
- Id (Артикул)
- Title (строка, не пустая)
- Status (На руках / Возвращенно / В фонде)

## 7. Критерии приемки (как проверить)
- Можно добавить 3 книги и увидеть список
- Можно поменять статус 1 книги
- Программа не падает при неправильном вводе

## 8. План модулей (черновик)
- Core (модели и логика)
- App (консольное меню)
- Storage (позже: сохранение/загрузка)
